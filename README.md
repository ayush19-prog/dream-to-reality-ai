# Dream-to-Reality AI

A Flask web app prototype that turns a user's early-stage idea into a structured project/business blueprint using Google's Gemini API.

## Features
- Premium responsive landing page and idea intake form
- Gemini-powered blueprint generation (when an API key is configured)
- Demo mode so the app can be explored without an API key
- SQLite project vault with saved blueprints
- Downloadable text report
- API key stays on the server; it is never sent to browser JavaScript

## Requirements
- Python 3.10+
- Internet connection for Gemini generation
- Gemini API key from Google AI Studio for real AI generation

## Run locally (Windows / VS Code)

1. Extract the ZIP and open the `dream_to_reality_ai` folder in VS Code.
2. Open the VS Code terminal and create a virtual environment:

   ```powershell
   py -m venv .venv
   .venv\\Scripts\\Activate.ps1
   ```

3. Install dependencies:

   ```powershell
   pip install -r requirements.txt
   ```

4. Copy `.env.example` to `.env` and add your Gemini API key.

   Get a key from Google AI Studio: https://aistudio.google.com/apikey

5. Load environment variables. Easiest option:

   ```powershell
   pip install python-dotenv
   ```

   Then add this line near the top of `app.py` (before reading environment variables):

   ```python
   from dotenv import load_dotenv
   load_dotenv()
   ```

   Alternatively, set the variables in PowerShell for the current terminal:

   ```powershell
   $env:GEMINI_API_KEY="your-key-here"
   $env:GEMINI_MODEL="gemini-2.5-flash"
   ```

6. Start the app:

   ```powershell
   python app.py
   ```

7. Open http://127.0.0.1:5000 in your browser.

## Demo mode
If `GEMINI_API_KEY` is not configured, the app generates a clearly labelled sample blueprint so you can test the interface. Demo output is not generated by an AI model. Add a valid API key to enable Gemini.

## Important notes
- Keep `.env` private. Never upload API keys to GitHub or place them in frontend code.
- This is an educational prototype, not a verified business, legal, tax, or investment adviser.
- Generated budgets and strategies are suggestions. Validate assumptions with real users and reliable sources.
- Before public deployment, turn off Flask debug mode, use a strong secret key, add authentication and per-user data access, apply rate limits, and review privacy/security requirements.
